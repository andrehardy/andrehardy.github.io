Andre Hardy's Portfolio
Welcome to my personal portfolio, a showcase of my expertise in cybersecurity, AI, and ERP systems. Built with a sleek, modern design inspired by innovative web portfolios, this site highlights my professional journey, projects like SETHIR (a symbolic AI system), and passion for secure, trust-based solutions. The deep indigo and gold color scheme symbolizes recursion, ethical ignition, encrypted memory, and inward intelligence.
Features

Single-Page Design: Responsive, smooth-scrolling layout with sections for About, Experience, Projects, Education, and Contact.
Symbolic Aesthetic: Lavender indigo (#6A5ACD) and gold (#FFD700) reflect precision, ethics, and innovation.
Projects: Showcases SETHIR, cybersecurity labs (Nmap, Wazuh, Autopsy), and this portfolio, with links to GitHub and Google Drive.
Tech Stack: HTML5, Tailwind CSS, Font Awesome, Google Fonts (Fira Code, Roboto Mono), and minimal JavaScript for interactivity.
Optimized: Lightweight with CDN-based assets and optimized images (<500KB).

Setup Instructions

Clone the Repository:git clone https://github.com/andrehardy/andrehardy.github.io.git
cd andrehardy.github.io


Run Locally:
Serve the site using Python’s HTTP server:python3 -m http.server 8000


Open http://localhost:8000 in a browser.


Optimize Images (if adding new ones):sudo apt install imagemagick
convert img/profile.jpg -resize 800x800 -quality 80 img/profile_opt.jpg


Deploy to GitHub Pages:
Push changes to the main branch:git add .
git commit -m "Update portfolio"
git push origin main


The site will be live at https://andrehardy.github.io.
